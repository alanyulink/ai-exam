## 1. 产品概述

基于现有AI考试题库（300道题目+6套模拟试卷），开发一个移动端优先的在线考试答题网站，方便用户在日常通勤、碎片时间使用手机进行刷题练习。

- **目标用户**：备考AI相关考试的学生和从业者，需要在手机上随时随地进行刷题练习
- **核心价值**：将本地题库转化为交互式答题体验，提供即时反馈和答案解析，帮助用户高效备考
- **使用场景**：日常通勤、排队等候、休息间隙等碎片化时间，通过手机浏览器快速刷题

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 直接访问网页，无需注册登录 | 浏览题库、刷题练习、模拟考试、查看解析 |

### 2.2 功能模块

1. **首页看板**：学习进度概览、快捷入口
2. **刷题模式**：按题型（单选/多选/判断）分类刷题，逐题作答，即时反馈
3. **搜题模式**（已上线，后期新增）：按题干关键词检索题目，列表 + 底部浮窗详情
4. **模拟考试**：完整模拟6套试卷（第6套为预测卷，40题/100分），限时答题，自动评分
5. **错题本**（已上线）：自动聚合答错题目（刷题与模考均记录），按题型筛选查看，支持查看解析、重新作答、单题移出、一键清空
6. **题目解析**：提交答案后立即显示正确答案和详细知识讲解（解析与答题反馈合并展示）
7. **学习统计**：答题数量、正确率、连续学习天数等数据在首页展示
8. **收藏**：在刷题/搜题页收藏题目

## 3. 核心流程

### 3.1 刷题流程

用户进入刷题模式 → 选择题型 → 查看题目 → 选择答案 → 即时显示正误 → 查看解析 → 下一题 → 循环直至完成

### 3.2 模拟考试流程

用户选择试卷 → 开始考试 → 倒计时开始 → 逐题作答 → 提交试卷 → 显示成绩报告 → 逐题回顾解析

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：简洁清新的学习工具风格，以白色和浅灰色为基底，搭配专注蓝为主色
- **主色调**：#2563EB（专注蓝），辅助色：#10B981（正确绿）、#EF4444（错误红）
- **按钮样式**：圆角大按钮（12px圆角），柔和阴影，点击有微缩反馈
- **字体**：系统原生字体（-apple-system），保证移动端最佳渲染
- **布局风格**：卡片式布局，内容区域居中，最大宽度640px（适配手机屏幕）
- **动效**：选项切换微交互动效，答题反馈弹跳动画，页面切换平滑过渡

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 统计卡片 | 毛玻璃效果卡片，大号数字+标签文字 |
| 首页 | 功能入口 | 三个大图标按钮，带微动效 hover/active 态 |
| 刷题页 | 题型Tab | 圆角胶囊式Tab切换，当前高亮 |
| 刷题页 | 答题区 | 题目卡片，选项列表（单选圆点/多选方块/判断开关） |
| 刷题页 | 反馈弹窗 | 底部弹出式卡片，绿色/红色背景，显示解析 |
| 模拟考试页 | 试卷卡片 | 横向滑动卡片列表，每张显示试卷概要 |
| 考试界面 | 顶部栏 | 固定顶部，显示倒计时、题号进度、退出按钮 |
| 成绩报告 | 结果面板 | 大号分数环形图，分项统计条形图 |
| 错题本 | 错题卡片 | 红色左边框卡片，显示题目摘要和错误次数 |

### 4.3 响应式设计

- **移动端优先**：以375px-414px（iPhone主流尺寸）为设计基准
- **平板适配**：最大宽度768px，内容居中，充分利用两侧空白
- **触控优化**：所有可点击元素最小44px触控区域，选项区域足够大方便手指点击
- **横屏适配**：检测横屏时合理利用横向空间，双栏显示

## 5. 数据来源

- 题目数据来源于本地题库文件（AI考试题库.md），共300题（单选200/多选50/判断50）
- 模拟试卷来源于5套试卷文件（AI考试模拟试卷_1.md ~ _5.md）+ 预测卷（AI考试预测卷.md），共6套
- 答案解析来源于3个答案与解析文件，已并入题库数据
- 所有数据通过构建脚本解析为结构化JSON（src/data/questions.json），再生成 js/data.js 供前端直接使用
