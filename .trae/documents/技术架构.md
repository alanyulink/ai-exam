## 1. 架构设计

```mermaid
graph TD
  "用户：手机/PC 浏览器" --> "静态资源：index.html + css + js"
  "静态资源：index.html + css + js" --> "原生 JS SPA（hash 路由）"
  "原生 JS SPA（hash 路由）" --> "题库数据 js/data.js（QUESTION_DATA）"
  "原生 JS SPA（hash 路由）" --> "LocalStorage（aiexam_ 前缀）"
  "LocalStorage（aiexam_ 前缀）" --> "学习统计 / 收藏 / 考试草稿 / 考试记录"
```

**架构说明**：纯前端静态站点，无后端、无构建步骤、无框架依赖。题目数据随 `js/data.js` 一次性加载；用户数据全部存于浏览器 LocalStorage（键前缀 `aiexam_`），无需注册登录。

## 2. 技术选型（实际）

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| 页面结构 | 原生 HTML + 字符串模板 | `index.html` + `js/pages/*.js` 的 `render()` 返回 HTML 字符串 |
| 样式 | 原生 CSS（单文件） | `css/style.css`，移动端优先，最大宽度 640px |
| 路由 | hash 路由 | `js/app.js` 监听 `hashchange`，按 `#/路径` 分发 |
| 状态/存储 | LocalStorage | `js/store.js` 统一封装读写 |
| 数据 | 静态 JS 对象 | `js/data.js` 中 `const QUESTION_DATA = {...}` |
| 数据生成 | Python 脚本 | Markdown → `src/data/questions.json` → `js/data.js` |
| 部署 | 静态文件 + Nginx | `deploy.sh` scp 到阿里云，`/tools/ai-exam/` |

> 注：本文件旧版曾按「React 18 + Vite + Tailwind + React Router」规划，实际实现未采用构建工具与框架，以此版本为准。

## 3. 路由定义

| hash 路由 | 页面 | 说明 |
|-----------|------|------|
| `#/` 或 `#/home` | 首页 | 学习统计看板 + 三个入口（刷题 / 搜题 / 模考） |
| `#/search` | 搜题 | 按题干关键词检索，列表 + 底部浮窗详情 |
| `#/practice/:type` | 刷题 | `type` ∈ `single` / `multi` / `judge` |
| `#/exam` | 模考列表 | 6 套试卷卡片 + 历史考试记录 |
| `#/exam/:id` | 考试界面 | 倒计时、答题、交卷 |
| `#/exam/:id/result` | 成绩报告 | 得分、逐题回顾、错题检查 |

其他路径回退到首页。

## 4. 数据模型（实际）

### 4.1 题目

```typescript
interface Question {
  id: number
  type: 'single' | 'multi' | 'judge'
  content: string
  options: { label: string; content: string }[]
  answer: string        // 多选如 "ABCD"
  explanation: string   // 解析
}
```

当前题库：300 题（单选 200 / 多选 50 / 判断 50）。题目未记录 `source` 字段。

### 4.2 试卷

```typescript
interface Exam {
  id: number
  name: string
  total_score: number      // 1-5 套 120 分，第 6 套 100 分
  per_score: number        // 1-5 套每题 2 分，第 6 套每题 2.5 分
  pass_score: number       // 1-5 套 72 分，第 6 套 60 分
  total_questions: number  // 1-5 套 60 题，第 6 套 40 题
  single_count: number
  multi_count: number
  judge_count: number
  time_limit: number       // 秒，均为 3600
  questions: Question[]    // 完整题目内嵌，含解析
}
```

### 4.3 用户数据（LocalStorage）

| key | 结构 | 用途 |
|-----|------|------|
| `aiexam_stats` | `{totalAnswered, totalCorrect, todayAnswered, todayCorrect, streakDays, lastStudyDate, totalExams, passedExams}` | 首页学习统计 |
| `aiexam_favorites` | `number[]` | 收藏题目 |
| `aiexam_examDrafts` | `{[examId]: draft}` | 考试中途进度 |
| `aiexam_examRecords` | `ExamRecord[]`（上限 50 条） | 历史成绩与错题回顾 |
| `aiexam_wrongQuestions` | `{[questionId]: {wrongCount, lastWrongTime}}` | 错题记录（仍写入，暂无独立页面展示） |

### 4.4 数据生成流程

```mermaid
flowchart LR
  "AI考试题库.md / 模拟试卷_1~5.md / 预测卷.md / 答案与解析.md" --> "scripts/parse_questions.py"
  "scripts/parse_questions.py" --> "src/data/questions.json"
  "src/data/questions.json" --> "scripts/generate_data_js.py"
  "scripts/generate_data_js.py" --> "js/data.js"
```

约定：

- `src/data/questions.json` 是**唯一数据真相源**（已被 `.gitignore` 忽略，需本地保留）。`js/data.js` 必须能由它经 `generate_data_js.py` 完整重建。
- 第 6 套试卷（预测卷）与答案修订已回写进 `questions.json`，不要用旧版本覆盖。
- 历史专用脚本仍保留在 `scripts/`：`generate_exam6.py`、`insert_exam6.py`、`replace_exam6.py`、`batch_update_answers.py`、`check_answer_errors.py`、`find_disputes.py`、`generate_answer_changelog.py`。修改题库后请走上面两步标准流程，避免再直接改 `js/data.js`。

## 6. 部署

| 目标 | 方式 | 地址 |
|------|------|------|
| 生产（主） | `./deploy.sh`：先 tar 备份到服务器 `/root/ai-exam-backup-<时间戳>.tar.gz`，再 scp `index.html`/`css`/`js`，最后本地与远端 md5 全量比对 | https://www.beeol.cn/tools/ai-exam/ |
| 服务器目录 | `/var/www/sites/beeol.cn/tools/ai-exam/`（Nginx alias，`sites-enabled/default` 内 `/tools/ai-exam/`） | — |
| 备用 | 推 `main` 触发 GitHub Actions 发布 `gh-pages` | https://alanyulink.github.io/ai-exam/ |

旧路径 `/ai-exam/` 由 Nginx 301 重定向到 `/tools/ai-exam/`；`beeol.cn` 301 到主域 `www.beeol.cn`。
